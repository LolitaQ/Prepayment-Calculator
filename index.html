Prepayment Calculator

Split insurance, road tax and other prepaid expenses by actual coverage days.

1. Financial year

Choose the FYE month. Expenses spanning multiple years will be split at each FYE automatically.

2. Add transactions

Supported: Description | Figure, Description [tab] Figure, or Description ending with the amount. Dates such as DD.MM.YYYY-DD.MM.YYYY, DD/MM/YYYY-DD/MM/YYYY, DD.MM.YY-DD.MM.YY or DD/MM/YY-DD/MM/YY are detected. Two-digit years are interpreted as 2000–2099 (e.g. 25 = 2025). Review parsed rows before calculating.

3. Results

Amounts are prorated using inclusive calendar days: segment days ÷ original Period Total days × original figure. The final segment is adjusted by any rounding cent so the split matches the original amount.
